# Diakrisis project overview

**Recorded:** 2026-10-26. **Scope status:** initial ten-package working scope authorized by owner instruction on 2026-10-26; no automatic acceptance of deliverables or milestones. **Owner:** Studio Zettlerei / interzettel (human owner acceptance required).

**Purpose:** Provide portable, source-grounded review skills and an evaluation harness for writing, scientific research, project documentation, and conceptual modeling.

**Intended users:** author/researcher; scientific investigator agents; repository-maintenance agents. **Value:** detect meaningful contradictions and unsupported claims with explicit evidence, while preserving original definitions and authorial intent.

**In scope (proposed):** upstream research; Agent Skills-compatible modular reviewers; versioned finding schema and authorities; baseline and post-skill tests; optional integration with Writing Kitchen, Spatial Laboratory, Project Record Standard and Personal Agent Stack; secure install/discovery; explicit versioning and drift checks.

**Out of scope:** replacing the source of truth in consuming repositories; giving LLMs authority to rewrite accepted decisions; automatic merges/deployments; requiring paid inference or external services; assuming that lexical fluency means epistemic validity.

**Success/acceptance criteria:** (1) skill discovery verified in chosen agent runtime; (2) objective schema checks pass; (3) human-adjudicated positive, negative and unfamiliar fixtures; (4) source-linked findings including abstentions and limitations; (5) reversible installation and integration with a consumer; (6) release evidence separate from repository commits.

**Constraints:** MIT project license; inspect upstream licensing; local-first; privacy and permission boundaries; source pinning; no fabricated citations; do not count work as Done without its gate.

**Readiness:** current L0 / **insufficient evidence for L1** in this new repository: no verified clean bootstrap, tested local runtime, or CI as of initial inspection. Proposed target L3 for first release, subject to owner determination. No new R0–R4 agent authority granted. Central readiness assessment not yet persisted; pending review with Personal Agent Stack policy.

**Unresolved decisions:** chosen first runtime; scope acceptance; publication/privacy policy for fixtures; acceptance and reviewer roles; release thresholds.
