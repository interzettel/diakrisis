# DIA-007 round 1: paired pilot on owner material (27 to 28 Oct 2026)

**Status:** results of one exploratory pilot. It is evidence of direction, not of an effect. Nothing here validates a skill or accepts a milestone.

**Publication:** the owner approved publishing these aggregate counts on 28 Oct 2026. The documents, findings, quotes and grades stay private.

## Design

The protocol is [docs/EVALUATION.md](../EVALUATION.md), registered before any run (protocol SHA-256 `06f17058…`).

**Material.** The owner supplied:

- a doctoral research proposal in an experimental revision with deliberately retained supplied wording;
- two essay drafts (v0.6);
- the two GitHub issues that serve as those essays' status ledgers.

The 8-word overlap with every skill file and fixture was zero.

**Skills under test.** Diakrisis at `654f5ee` (contract revision 2).

**Cells.** 12 cells, each run once per arm:

- proposal: all six specialist review types;
- each essay: argument and communication;
- each ledger: consistency.

**Arms.** The skill arm read the specialist `SKILL.md` and the contract. The baseline arm had no Diakrisis files. Everything else was identical: model, task line, tool access, a cap of 6 findings, and the output shape.

**Blinding.** Findings were pooled and shuffled per document, with the arm key sealed (SHA-256 `e5e98d64…`) and opened only after every ID had a frozen verdict.

## Graders

The owner could not grade 138 findings, which is a deviation. Instead, the protocol's agent graders answered every ID on the owner's own threads, blind to arm:

| Document | Grader | Notes |
| --- | --- | --- |
| Essays and ledgers | The AI assistant that edited the essays' v0.5/v0.6 | Project-informed; self-review bias stated by the grader |
| Proposal | ChatGPT (Codex) | Project-informed; froze its ID-level judgments in the owner's repository before unblinding |

The owner graded one finding himself before those responses: P-72, graded wrong.

The reviewers were Claude agents, so the proposal grader is a different model family. A second, non-blind Claude opinion on the proposal is not counted.

**Verdicts.** Each finding got one of:

- `agree`: the bounded diagnosis is endorsed;
- `partly`: a useful concern, but overstated or with an unsafe remedy;
- `disagree`: the diagnosis is rejected on the evidence;
- `duplicate`: the proposal grader marked repeats instead of grading them.

## What the graders' feedback says, by arm

- **Both arms.** The same error appeared in each: a public role description treated as contradicting the owner's own account (one finding per arm). Both arms also produced a remedy that demanded an extra experimental arm.
- **Skill arm.** Two remedies would have introduced new problems: measuring co-presence by headcount, which changes the construct, and excluding interviewed people, which creates selection bias.
- **Baseline.** All five examples in the essay grader's "what should improve" list came from the baseline:
  - reading unavailable evidence as absent;
  - asking a historical account for a controlled comparison;
  - an incomparable counterexample;
  - an unsafe financial rewrite;
  - a disputed record check.
- **Cross-arm duplicates.** Graders also criticised duplicated findings. These are expected because the arms overlap by design, and the pilot did not run the coordinator, whose job is to merge duplicates.

## Limits

These are {expert inference}:

- One run per cell, so differences may be run-to-run variation.
- The graders are project-informed, and "agree" versus "partly" is a judgement call.
- The proposal revision was visibly corrupted, so many proposal findings describe one underlying defect. The proposal grader and a second assistant both said a clean but flawed manuscript is needed.
- Recall was not measured, because the owner's known-problem list was not collected.

## Deviations from the registered protocol

These are CONSORT 2025 item 10 deviations:

1. 21 of 24 runs hit a session usage limit. They were resumed from where they stopped, with no new instructions.
2. Grading was done by agent graders on the owner's threads instead of by the owner, except one owner-graded finding.
3. The proposal grader used `duplicate` as a verdict instead of grading each repeat.
